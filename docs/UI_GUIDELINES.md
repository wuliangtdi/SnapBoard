# SnapBoard UI 指南

## 1. 定位

SnapBoard 是高频桌面效率工具，界面应安静、紧凑、键盘优先。避免营销式大标题、装饰性渐变、卡片套卡片和占用大量空间的说明文字。

## 2. 快速窗口

- 打开后焦点进入搜索框，输入立即过滤。
- 列表使用稳定行高、虚拟化和按需预览。
- 文本预览最多显示有限行，长单词、URL 和路径必须换行或截断。
- 图片只加载缩略图，选择后才按目标区域尺寸解码预览。
- 预览区和历史区用分隔线组织，不把整个页面做成浮动卡片。
- 空、加载、错误、同步冲突和权限受限都必须有独立状态。

## 3. 控件选择

- 搜索使用 TextBox；模式使用分段控件；二元设置使用 Toggle/CheckBox。
- 类型、设备和排序使用菜单或筛选列表。
- 数值使用输入框、步进器或滑块，不用文字按钮模拟。
- 常见命令使用统一图标库；不手绘风格不一致的 SVG。
- 不熟悉的图标提供 Tooltip，但不在主界面堆放使用教程。

## 4. 视觉

- 中性色承载主体，强调色只用于选择、焦点和关键状态。
- 卡片圆角不超过 8 px，不在卡片内部再嵌套卡片。
- 紧凑面板使用紧凑字号；只有真实品牌首页才使用大字号。
- 支持浅色、深色、高对比度和系统缩放；当前 Phase 1.0 壳只完成浅色基线。

## 5. 可访问性

- 所有核心操作都可用键盘完成，焦点顺序可预测。
- 焦点可见，文字和图标满足合理对比度。
- 不只依靠颜色表达错误、同步或置顶状态。
- 200% 缩放和最小窗口尺寸下文本不能互相遮挡。
- 动画短且可关闭，不使用持续背景动画。

## 6. 参考边界

可研究 Ditto、Maccy、CopyQ 和 PasteBar 的信息层级与工作流，但不复制其品牌、图标、截图、主题代码或受限制资产。

## 7. 已选视觉基线：Command Center

第一轮正式视觉方向采用第 2 版“命令中心”方案：顶部品牌与搜索、第二行类型筛选、左侧连续历史列表、右侧所选内容预览和底部状态栏。页面不使用浮动卡片或装饰背景。

- 参考稿：`docs/design/snapboard-command-center-reference.png`。
- 实现截图：`docs/design/snapboard-command-center-implementation.png`。
- 设计 QA：根目录 `design-qa.md`。
- 默认窗口：1305 x 900 DIP，最小窗口 980 x 700 DIP。
- 视觉对照画布：1487 x 1058，1:1 Skia Headless 渲染。
- 主区域比例：历史列表 49%，预览 51%；紧凑模式折叠预览区。
- 列表行高：79 DIP；选中项使用淡蓝底和 3 DIP 蓝色左边线。
- 主强调色：`#1677FF`；成功 `#2DBE78`；警告 `#F59E0B`；危险 `#EF4444`。
- 代码预览使用轻量只读着色，不引入完整编辑器或 Roslyn 运行时。

设置和紧凑模式使用图标加 Tooltip，不在工具栏重复显示文字说明。参考稿底部的快捷键教程条未保留，因为快捷键帮助应进入设置或命令菜单，主界面只显示当前状态。
