# SnapBoard 需求与范围

> 版本：0.1 规划基线
> 产品：SnapBoard（闪剪）
> 许可证：MIT

## 1. 产品目标

SnapBoard 面向长期高频使用剪贴板的开发者、办公人员和内容工作者。核心体验是通过全局快捷键快速找到历史内容并粘贴，同时允许用户在自己的 WebDAV 服务上同步数据，而不把明文交给服务提供方。

## 2. 第一期 Windows 功能

### 2.1 历史采集

- 监听 Windows 11 剪贴板变化。
- 保存 Text、HTML、RTF、图片和文件引用元数据。
- 处理剪贴板占用、延迟渲染、重复通知和本应用写回循环。
- 支持暂停采集、应用黑名单、仅文本规则和最大载荷限制。
- 默认过滤常见密码管理器与临时/机密格式。

### 2.2 检索与粘贴

- 全局快捷键打开快速窗口。
- 按正文、来源应用、类型、时间、标签和置顶状态筛选。
- 支持键盘导航、普通粘贴和纯文本粘贴。
- 自动粘贴受权限限制时降级为复制后由用户手动粘贴。
- 搜索 100,000 条文本历史时 P95 小于 80 ms，发布失败线为 200 ms。

### 2.3 管理

- 置顶、标签、删除、清空、自动过期和容量上限。
- 相邻相同内容默认合并，但置顶内容不自动合并。
- 图片使用缩略图和按需解码，不在列表中加载原始图像。

### 2.4 WebDAV 同步

- 第一版同步 Text、HTML、RTF 和图片。
- 文件引用可以保存在本机，但不传输文件本体。
- 支持设备离线、幂等重试、删除 Tombstone、设备撤销和手动同步。
- 默认关闭，用户主动启用后才上传。
- WebDAV 服务端只能看到加密对象、大小和访问时间，不能读取内容明文。

## 3. 第二期 macOS

- 使用 NSPasteboard changeCount 或等价稳定机制采集变化。
- 使用 Keychain 保存凭据和密钥。
- 全局快捷键、自动粘贴和焦点恢复遵守辅助功能权限。
- 同步协议、数据库模式和 UI 用例与 Windows 保持兼容。

## 4. 第三期 Linux

- 优先支持 Ubuntu、Fedora、Debian、Linux Mint 的当前主流版本。
- X11 提供完整目标能力。
- GNOME Wayland 允许配套 Shell 扩展；没有扩展时明确标记为受限模式。
- KDE Plasma Wayland 根据 Clipboard/Portal/桌面接口验证结果分级支持。
- 凭据使用 Secret Service 或 KWallet。

## 5. 非功能要求

| 类别 | 要求 |
| --- | --- |
| 运行内存 | 托盘空闲目标 <= 80 MB，发布失败线 > 100 MB |
| 启动 | 快速窗口暖启动 P95 < 120 ms |
| CPU | 空闲平均 < 0.3%，失败线持续 > 1% |
| AOT | 正式客户端全部 Native AOT，未解释警告为零 |
| 安全 | HTTPS、E2EE、系统凭据存储、正文不进入日志 |
| 可维护性 | 单向依赖、架构测试、关键中文注释、详细进度记录 |
| 可访问性 | 键盘完整操作、合理对比度、焦点可见、文本不截断 |

## 6. 首个正式版本不包含

- 文件本体同步、大文件断点续传和远端病毒扫描。
- OCR、AI 分类、内容改写和云端全文搜索。
- 任意脚本或第三方插件执行。
- 团队空间、组织权限、浏览器和移动端客户端。

## 7. 验收原则

功能完成必须同时满足：JIT 与 AOT 行为一致、自动测试通过、目标平台实机可操作、性能不越线、权限降级明确、计划和进度文档已更新。
